🎨 Paletas de Cores por Categoria - Mapa Interativo

Sobre as Cores

Cada categoria de dados do Mapa Interativo possui uma paleta de cores única e harmoniosa, baseada nos padrões visuais dos mapas estáticos do Anuário. As cores foram selecionadas para:

  • Acessibilidade: Garantir contraste adequado entre os tons
  • Consistência: Manter o padrão visual dos mapas originais
  • Clareza: Facilitar a interpretação dos dados mediante gradientes visuais
  • Marca: Reforçar a identidade visual de cada categoria

Características da Implementação

  • ✅ Paletas Dinâmicas: Cada categoria carrega sua própria paleta de cores automaticamente
  • ✅ Badge Colorido: Indicador visual mostra qual categoria está sendo visualizada
  • ✅ Legenda Interativa: Mostra os intervalos de valores com as cores correspondentes
  • ✅ Hover Effects: As cores da legenda ganham sombra e efeito visual ao passar o mouse
  • ✅ 22 Indicadores Totais: Todos utilizando as paletas específicas de suas categorias
