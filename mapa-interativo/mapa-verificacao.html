Como testar o mapa

  1. Clique no botão "Executar Diagnóstico Completo" para verificar o status de todos os componentes
  2. Verifique o console acima para mensagens detalhadas e possíveis erros
  3. Se tudo estiver OK (✅), clique em "Abrir Página do Mapa" para visualizar o mapa
  4. Na página do mapa:
    • O mapa deve aparecer na primeira aba (Mapa)
    • Selecione uma "Categoria" (ex: Demografia)
    • Selecione um "Indicador" (ex: População)
    • Clique nas outras abas (Ranking, Histórico, Filtros, Comparação) para testar as funcionalidades
