❓ PERGUNTAS FREQUENTES:

P: Por que é tão mais rápido agora?
R: Porque carregamos apenas os dados de cada temática, não tudo de uma vez!

P: Posso usar offline?
R: Sim! Abra index.html direto no navegador ou use o servidor local.

P: Os downloads não funcionam
R: Certifique-se que tem internet (para as bibliotecas JavaScript).
   Se estiver usando o navegador localmente, use o servidor.py.

P: Onde ficam os dados principais agora?
R: Na pasta dados_repositorio/, com índice em dados_repositorio/manifest.json

P: Como adicionar mais dados?
R: Adicione os CSVs em dados_repositorio/ e atualize o manifest.json.
